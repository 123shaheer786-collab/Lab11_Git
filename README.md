\# Storage Estimator - Main Version

\## Purpose

A simple Python program that converts a file size in megabytes (MB) into kilobytes (KB) and bytes.



\## How to Run

1\. Make sure Python is installed.

2\. Open a terminal in this folder.

3\. Run: python storage\_estimator.py

4\. Enter a file size in MB when asked.



\## Example

Input:

Enter file size in MB: 5



Output:

5.0 MB = 5120.0 KB

5.0 MB = 5242880.0 bytes
